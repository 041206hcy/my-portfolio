# 旅行照片站 · 复合版式改造设计说明

> 基线：`public/index.html` + `public/styles.css` + `public/home.js`（暖纸 #f7f3ea／墨 #2b2620／砖红 #b4543a，标题宋体、正文黑体）
> 目标：从「一张长条单页」变成「有刊头、有目录、有跨页、有独立栏目的旅行手记」
> 数据边界：不新增后端字段。全部页面只消费 `GET /api/site` 已有的 `photos[]` / `trips[]` / `stats{}`

---

## 一、现状诊断：单调不是因为内容少，是因为"每屏长得一样"

逐节对照现有代码，五个可量化的原因：

| # | 问题 | 证据 |
| --- | --- | --- |
| 1 | **容器宽度单一** | 全站只有 `.page--wide { --maxw: 1180px }` 一种宽度，hero / map / trips / wall 全部锁在同一列宽里，眼睛找不到"换章"的信号 |
| 2 | **区块标题是同一个模板** | 四个区块都用 `.section__title`（21px 宋体 + 细线 + 44px 砖红短线），四次重复，标题层级失去信息量 |
| 3 | **同一屏里没有主次** | hero 是纯文本（`.hero__name` 42px + 三行灰字 + 三个按钮），页面上**没有任何一张照片出现在首屏**，而这是一个照片站 |
| 4 | **卡片与网格同质** | `.trips` 与 `.wall` 都是 `repeat(auto-fill, minmax(...))` 等宽网格，旅程卡与照片卡在观感上是同一种"方块流" |
| 5 | **背景与留白是常量** | `main` 只有一种 `--bg`，`.section { padding: 48px 0 8px }` 节节相同，没有"松—紧—松"的呼吸 |

> 结论：需要的是**版式语法**（band／跨列／错版／满版），不是更多内容。

## 二、信息架构

### 2.1 页面清单（8 个，全部静态可托）

| 路由 | 文件 | 职责 | 数据来源 | 优先级 |
| --- | --- | --- | --- | --- |
| `/` | `index.html` | 复合导览：刊头 + 目录条 + 最近旅程 + 地图 + 旅程索引 + 照片墙 + 笔记 + 版权页 | `/api/site` | P0 |
| `/journeys` | `journeys.html` | 旅程年表：按年份分组，全年份目录 | `trips` + `photos`（按 `trip_id` 计数） | P1 |
| `/journey?id=` | `journey.html` | 单趟旅程详情：封面跨页 + 概要条 + 局部地图 + 时间序照片流 + 前后翻页 | 按 `trip_id` 过滤 | P1 |
| `/map` | `map.html` | 全景地图 + 地点索引（可键盘操作的地点列表 ⇄ 地图联动） | `photos` 中有 `lat/lng` 的 | P1 |
| `/photos` | `photos.html` | 照片库：按年份／旅程筛选，分组瀑布流，沿用 120 张分批 | `photos` | P1 |
| `/notes` | `notes.html` | 笔记索引（现有 `notes/*.html` 两篇，缺一个入口） | 手写 | P2 |
| `/about` | `about.html` | 已有，仅统一导航与页脚 | 手写 | P2 |
| `/404` | `404.html` | 已有 | — | — |

**URL 方案（不引入构建、不改 Worker 路由）**：`/journey?id=12` 这类"查询串 + 静态壳 + 客户端渲染"，Cloudflare 静态资源会把 `/journey` 映射到 `journey.html`，无需在 `src/index.js` 增加任何分支。
代价：详情页对爬虫不友好。若日后要 SEO，再在 `src/index.js` 里给 `/journey/*` 加一条服务端渲染分支（P2，本期不做）。

### 2.2 导航结构

```
黄翀与的旅程 ──────── 旅程 · 地图 · 照片 · 笔记 · 关于
                        ↑ 当前页：砖红 2px 下划线 + aria-current="page"
```

- 五项，平级，不设下拉；`关于` 从首页正文里移出，首页只留一句自我介绍。
- 移动端：导航单行 44px 高、横向滚动（`overflow-x:auto` + 隐藏滚动条），**不放汉堡菜单**——五个短词直接露出比隐藏更快，也满足 44px 触摸目标。

### 2.3 首页与子页的分工（防止首页变成超长滚动）

首页只做三件事：**给出身份 → 给出空间感（地图）→ 给出时间入口（旅程）**。
每个栏目在首页只放"一个代表性切片 + 一句说明 + 一个去向"，完整内容交给子页：

| 栏目 | 首页放多少 | 子页放多少 |
| --- | --- | --- |
| 旅程 | 1 次"最近一次"+ 3 张卡（共 4 张封面） | `/journeys` 全部；`/journey` 单趟全部照片 |
| 地图 | 1 张 520px 地图（打点聚类） | `/map` 全屏地图 + 地点列表 |
| 照片 | 1 条横滑胶片条（8 张）+ 12 格错版墙 | `/photos` 全部，分批 120 |
| 笔记 | 2 条 | `/notes` 全部 |

**首页图片预算：≤ 25 张**（4 封面 + 8 胶片 + 12 墙 + 1 叠图 ≈ 25，可复用同一批 key 去重），文字预算 ≤ 450 字。超了就往下推给子页。

### 3.2 12 列基线网格（所有复合版式的公共底座）

```css
/* 12 列：跨列比例一律取 6/6、7/5、4/4/4、6/3/3 —— 不要出现 5.5 这种列 */
.page--wide { --maxw: 1180px; --gutter: var(--space-5); }   /* 20px */

.sheet {
  display: grid;
  grid-template-columns: repeat(12, minmax(0, 1fr));
  gap: var(--gutter);
}
/* 语义化跨列类，避免在 HTML 里写 grid-column: 4 / span 5 这种魔法数 */
.c-4  { grid-column: span 4; }
.c-5  { grid-column: span 5; }
.c-6  { grid-column: span 6; }
.c-7  { grid-column: span 7; }
.c-8  { grid-column: span 8; }
.c-12 { grid-column: 1 / -1; }

@media (max-width: 1023px) { .sheet { --gutter: var(--space-4); } .c-5,.c-6,.c-7,.c-8 { grid-column: 1 / -1; } }
@media (max-width: 767px)  { .c-4 { grid-column: 1 / -1; } }
```

### 3.3 段落（band）与满版

```css
.band { padding: var(--space-16) 0; }                    /* 桌面 64px；关键段落用 96px */
.band--tight { padding: var(--space-10) 0; }
.band--soft  { background: var(--bg-soft); }
/* 满版：背景/地图铺到视口边缘，内容仍留在 1180 容器内 */
.band--bleed { width: 100vw; margin-inline: calc(50% - 50vw); }
html { overflow-x: clip; }                                /* 防满版横向滚动条 */
```

节奏规则（照做即可拉开层次）：
1. **背景只在"换章"处变**：刊头 `--bg` → 目录条 `--bg-soft` → 最近旅程 `--bg` → 地图 `--bg-soft`（满版）→ 旅程索引 `--bg` → 照片墙 `--bg` → 笔记 `--bg-soft` → 版权页 `--text` 反白。
2. **同背景相邻段落之间用 1px `--line` 细线分隔，不同背景之间不加线**（避免"线 + 色块"双信号打架）。
3. 满版只用两次：地图段、版权页。用多了就不是"满版"而是"没有容器"。

### 3.4 区块标题组件（替代现有 `.section__title` 的四处复制）

新结构 = 编号 + 标题 + 副题 + 右侧动作，细线在**整段下方**而不是标题下方：

```html
<header class="head">
  <p class="head__no">03</p>
  <h2 class="head__title">旅程索引</h2>
  <p class="head__sub">按年份排，点开是一整趟</p>
  <a class="head__more" href="/journeys">全部 6 趟 →</a>
</header>
```

```css
.head { display: grid; grid-template-columns: auto 1fr auto; align-items: end;
        gap: var(--space-2) var(--space-4); padding-bottom: var(--space-3);
        border-bottom: 1px solid var(--line); margin-bottom: var(--space-8); }
.head__no { font-family: var(--font-serif); font-size: var(--fs-xl); color: var(--accent);
            margin: 0; line-height: 1; letter-spacing: .04em; }
.head__title { font-size: var(--fs-2xl); margin: 0; line-height: 1.2; }
.head__sub { grid-column: 2; margin: 0; color: var(--muted); font-size: var(--fs-sm); }
```

**编号是本版式的"章号"**：01 旅程年表 / 02 地图 / 03 照片 / 04 笔记 …连续编号跨越首页与子页，读起来像手记的目录，也是"复合"最便宜的证据。

## 四、首屏构图

### 4.1 三个方案与取舍

| 方案 | 构成 | 优点 | 风险 | 结论 |
| --- | --- | --- | --- | --- |
| **A 双栏错版**（推荐） | 左：刊头文字（6 列）；右：三张相纸错位叠放（5 列） | 照片立刻进首屏；纸/墨/相纸三元素一次到位；不动素材即可做 | 需要 3 张有代表性的照片 | **采用** |
| B 满版封面压字 | 一张满版封面 + 纸片标题横压在图片下缘 | 最有冲击力 | 无大图时塌方；首屏全靠一张图，慢网会白屏 | 只在 `/journey` 详情页用 |
| C 版画式双线框 | 细线双框 + 中央一枚小图 + 大字 | 最"文人气" | 信息量太低，不像照片站 | 作为 404／空状态样式 |

### 4.2 方案 A 的尺寸与构图参数

| 要素 | 规格 |
| --- | --- |
| 刊头眉标（kicker） | 12px／`--fs-xs`／`letter-spacing: .18em`／`--muted`／全大写风格中文用「·」分隔：「旅行手记 · 2019 — 2026」 |
| 主标题 | 宋体 600，`clamp(40px, 5.2vw, 64px)`，`line-height 1.14` |
| 砖红短线 | 44×2px，标题下方 16px，与现有 `.section__title::after` 同一记号（**全站只此一种红色记号**） |
| 副标（tagline） | 18px，字距 .12em，`--accent-ink`（见 §7.3 对比度修正） |
| 导语 | ≤ 3 行、≤ 34 字/行，`--ink-2`，正文黑体 15px |
| 统计行 | 三个数字用宋体 24px，单位/说明 14px 灰；分隔点用 `·`（`--rule-strong`） |
| 按钮 | 主按钮砖红实底 + 一个次按钮描边；**第三个按钮删掉**（「关于我」进导航），首屏动作最多两个 |
| 页脚小字条 | 三组元信息，12px，顶部 1px 细线，与叠图底边齐平 |

### 4.3 叠图（相纸）几何

```css
.plate { background: #fffefb; border: 1px solid var(--line); border-radius: 2px;
         padding: 7px 7px 0; box-shadow: 0 1px 2px rgba(43,38,32,.07); }
.plate--main   { width: 76%; aspect-ratio: 4 / 5; margin-left: 24%; transform: rotate(1.2deg); }
.plate--sub    { width: 46%; aspect-ratio: 3 / 4; position: absolute; left: 0; bottom: 0;
                 transform: rotate(-2.4deg); }
.plate--stamp  { width: 30%; aspect-ratio: 1 / 1; position: absolute; right: 4%; bottom: 12%;
                 transform: rotate(2.8deg); }
```

- **旋转上限 ±3°**，再多就从"手记"变成"歪掉的网页"。
- 三张图**不可等大**，用 76% / 46% / 30% 的宽度差制造纵深；主图右上角对齐容器右上角。
- 图的角落压一枚坐标 chip（`34.5°N 108.0°E`，12px，`--bg` 半透明底 + 1px 描边），替代"说明照片是什么"的图注——这是全站唯一的"地理标签"记号。
- 悬停：只允许主图 `transform: rotate(0deg) scale(1.01)`，其余不动；`prefers-reduced-motion` 下取消。

## 五、栏目顺序与视觉节奏

### 5.1 顺序与理由

`刊头 → 目录条 → 最近旅程 → 地图 → 旅程索引 → 照片墙 → 笔记 → 版权页`

1. **照片必须进首屏**（现在没有，这是"单调"的第一原因）。
2. **目录条放在刊头之后**：它是"本期的页目"，位置必须像杂志目录一样紧随刊头，同时用 104px 的紧凑段把首屏和正文切开（松→紧）。
3. **地图排在旅程之前**：地图回答"在哪儿"（空间），旅程回答"哪一趟"（时间），先空间后时间符合看图直觉；且地图是本站最强差异化内容，不该被压到第三屏。
4. **旅程索引在照片墙之前**：旅程是叙事单位，照片墙是证据；有叙事先看叙事。
5. **笔记与版权页收尾**：笔记是"延伸阅读"，版权页用深色反白做"合上书"的句号。

### 5.2 节奏表（照此实现就不会平均）

| 序 | 段落 | 背景 | 上下留白 | 图片 | 文字 | 视觉重量 | 手法 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| — | 刊头 | `--bg` | 48 / 40 + 74svh | 3 | 60 字 | ●●● | 双栏错版、叠纸、旋转 |
| — | 目录条 | `--bg-soft` | 24 / 24（高 104） | 0 | 4 项 | ● | 编号 + 大字 + 箭头，横向四格 |
| 01 | 最近旅程 | `--bg` | 96 / 96 | 4 | 120 字 | ●●● | 7/5 跨列、3 张小图成"胶片条" |
| 02 | 地图 | `--bg-soft` 满版 | 96 / 88 | 1（交互） | 60 字 | ●● | 满版色块、纸面地图、角标坐标 |
| 03 | 旅程索引 | `--bg` | 96 / 96 | 4 | 100 字 | ●● | 左侧粘性年份栏、首卡跨两列 |
| 04 | 照片墙 | `--bg` | 80 / 96 | 12 + 8 | 60 字 | ●●● | 横滑胶片条 + 12 格错版墙 |
| 05 | 笔记 | `--bg-soft` | 72 / 72 | 0 | 80 字 | ● | 纯文字，日期左栏，细线分隔 |
| — | 版权页 | `--text` 反白 | 56 / 56 | 0 | 120 字 | ● | 深色收束、四栏、回顶部 |

节奏读法：**松（首屏）→ 紧（目录条）→ 松（跨页）→ 中（地图）→ 中（索引）→ 松（照片）→ 紧（笔记）→ 紧（页脚）**。视觉重量序列 `3-1-3-2-2-3-1-1`，永远不出现连续三段同重量。

### 5.3 各段落的具体版式要点

**① 目录条（新增，最省力也最见效）**
四格，每格：`01`（宋体 21px 砖红）+ 栏目名（17px）+ 一句 6–8 字说明（13px 灰）+ `→`。整格可点，`height: 104px`，格间 1px 竖线；`--bg-soft` 底。移动端 `display:flex; overflow-x:auto; scroll-snap-type:x mandatory`，每格 `flex: 0 0 78vw`。

**② 最近旅程（跨页）**
左 7 列：封面 `aspect-ratio: 4/3`，与纸面同色 1px 描边；右侧 5 列：kicker「最近一次」+ 宋体 28px 标题 + 元信息行（日期 · 张数 · 地点数）+ 摘要 2 行 + `读整趟 →`；文字列下方接 3 张 1:1 小图（72px，gap 8px）做成"胶片条"，暗示"还有更多"。

**③ 地图（满版段）**
`--bg-soft` 满版，内部容器 1180；左标题 + 右侧图例（`06 个地点 · 138 个点`）；地图 `height: 520px`（移动 320px），**保留 1px `--line` 描边 + 4px 圆角**，让地图像一张贴在纸上的图版（这是现有 `.map` 已经具备的质感，只把高度和满版底加上去，是性价比最高的一处）。

**④ 旅程索引**
左 3 列：粘性年份（宋体 48px，`2026` / `2025` / `2024`，滚动时高亮当前年）；右 9 列：2 列卡，**每年第 1 张卡跨两列并改用 16:9 封面**，其余 4:3。卡片去边框，改用 `border-top: 1px` + 内边距，观感从"卡片流"变成"报纸栏目"。

**⑤ 照片墙**
两层：先一条 `overflow-x: auto` 的胶片条（`scroll-snap`、8 张、每张 220×160、露出第 5 张的一半作为"还有"的提示），再接 12 格错版墙。错版模式（按 12 格循环）：

```
[ 4 ][ 4 ][ 4 ]     ← 三张等宽
[ 6 ][ 3 ][ 3 ]     ← 一张主图
[ 3 ][ 6 ][ 3 ]
[ 4 ][ 4 ][ 4 ]
```
错版墙里只有 `[6]` 那几张保留拍立得白边（`.wall__item` 现有样式），其余改为无边框裸图 + 图注在下方 12px 灰字。**这是"繁杂但不乱"的关键：同一屏只允许一种"相纸"，其余都是纯图。**

**⑥ 笔记**：两行，左侧日期（12px 灰，宽 96px 固定列），右侧标题 + 摘要；行间 1px 细线；`--bg-soft` 底。

**⑦ 版权页（深色反白）**：`background: var(--text); color: #f0ead9`，四栏：站名 + 一句话 / 站点统计 / 栏目链接 / 更新时间与版权；末行居中 12px。深色段是"合上书"，也是全站唯一深色区——现在全站没有暗部，这是"平"的隐藏原因之一。

## 六、子页版式要点（每页一个"记忆点"）

### `/journeys` 旅程年表
左侧 `position: sticky; top: calc(var(--nav-h) + 24px)` 的年份大数字 + 每年张数；右侧 2 列卡片。年份切换用 `IntersectionObserver` 高亮。**记忆点：年份当章节号，纵向读下来像一本编年册。**

### `/journey?id=` 单趟详情
1. **封面跨页**（方案 B）：`height: clamp(380px, 56svh, 560px)`；标题不压在图上，而是做成一张 `--card` 纸片横压图片下缘（`margin-top: -56px`，左对齐 2 列缩进），保证文字对比度恒定。
2. **概要条**：三格（日期 / 天数 / 张数），宋体数字 28px，1px 细线分隔。
3. **局部地图**：`height: 320px`，只画本趟的点；**点数 ≥ 4 时按 `shot_at` 顺序连成 `L.polyline`**（虚线 1.5px 砖红，`opacity .55`），这是"轨迹"感最便宜的实现，无需新字段。
4. **照片流**：按时间排序，交错跨列 `5/7 → 7/5 → 4/4/4`，每张图下 12px 图注（地点 · 日期）。
5. **前/后翻页**：`上一趟 ←` / `→ 下一趟`，宋体 21px，独占一行，`border-top`。

### `/map` 全景地图
左 380px 地点索引（按年份分组，每行：地点 + 张数），点击 `map.flyTo` 并打开该点首个弹窗；右地图 `height: calc(100svh - var(--nav-h))`，`position: sticky`。**这个列表同时是无鼠标用户访问地图内容的替代路径**（Leaflet 标记默认不可 Tab，列表是必须项，不只是装饰）。

### `/photos` 照片库
筛选条吸顶（`top: var(--nav-h)`）：全部 / 按年份 / 按旅程；结果按 `trip_id` 或年月分组，组标题粘性。沿用 `BATCH = 120` 分批 + 「再看 120 张」。

### 7.3 对比度修正（实测，可复现）

现有两个色在纸底上**都差一点点**：

| 组合 | 实测 | AA（正文 4.5:1） | 处理 |
| --- | --- | --- | --- |
| `--muted #7a6f61` on `--bg #f7f3ea` | **4.44 : 1** | ✗ 差 0.06 | 改 `--muted: #6f6355` → **5.28 : 1** ✓ |
| `--accent #b4543a` on `--bg`（链接、副标） | **4.44 : 1** | ✗ | 新增 `--accent-ink: #9d4630` → **5.66 : 1** ✓，用于**正文级**文字；`--accent` 仅用于 ≥ 21px 标题、2px 短线、按钮底色 |
| `--tag-text #8a4a30` on 标签底（`accent-soft` 叠纸） | 5.38 : 1 | ✓ | 不动 |
| `--on-accent` on `--accent`（主按钮） | 4.9 : 1 | ✓（白字 14px 需 4.5） | 不动 |

> 影响面：只要改 `--muted` 一个变量，全站图注、元信息、说明文字同时过线。这是本次唯一必须做的无障碍修正。

### 7.4 现有代码的两处小问题（顺带修）

1. `body::after` 的纸纹层 `z-index: 9999` 压在灯箱（`1000`）之上。因 `pointer-events: none` 不影响操作，但会在全屏大图上蒙一层颗粒。建议降为 `z-index: 1` 并给灯箱 `z-index: 2000`。
2. 导航链接可点区域只有文字高度（约 22px），低于 44px 触摸目标。加 `padding: 11px 4px` 即可，视觉不变。
