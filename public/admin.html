照片站管理后台

需要管理口令

这个后台只有你本人能用。口令保存在这台设备的浏览器里；服务端只存它的 SHA-256 哈希，不存明文。

上传照片

选好图后会在你自己的浏览器里压成两档再上传：缩略图长边 400px、网页图长边 1600px（WebP）。 原图不上传，留在你硬盘里。拍摄时间、位置会尽量从照片的 EXIF 里自动读出来。

    待标点 0

    没有 GPS 的照片都落在这里（微信/QQ 传过的图会被抹掉 EXIF，相机照片也常常没有位置）。 在下面地图上点一下 → 写个地名 → 给选中的照片打点，一次能打一批。

    还没在地图上选点。

    照片管理 0

    可见性三档：公开（上首页、进 sitemap）、仅链接（不在列表里，拿到直链能看）、仅自己（只在管理页看得到）。

    旅程

    一次旅程 = 名字 + 起止日期 + 一组照片。之后单次旅程页（地图 + 轨迹回放 + 票据）会挂在它下面。

    机票 / 火车票的 OCR 录入、真实轨迹（铁路线 / 大圆航线）在第二轮加进来，先把「传图 → 标点 → 地图上看到」这条链跑通。

    本期文字

    首页上那些「编辑位置」的话都由你写：刊头导语、本期手记、方法卡、页脚。留空就用内置的默认文案。 边注一行一条，会按顺序排在首页手记旁边。这些文字存在 settings 表里（键名前缀 copy.）， 首页里的张数、地点数、年份跨度是接口自己算的，不用手写。
