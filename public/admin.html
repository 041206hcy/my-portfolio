    旅程

    一次旅程 = 名字 + 起止日期 + 一组照片。之后单次旅程页（地图 + 轨迹回放 + 票据）会挂在它下面。

    机票 / 火车票的 OCR 录入、真实轨迹（铁路线 / 大圆航线）在第二轮加进来，先把「传图 → 标点 → 地图上看到」这条链跑通。
